Data Manager

Add, edit, and download updated data files for your website

How It Works

  1. Your current data is loaded from inventory.js, collection.js, and pairings.js
  2. Add new animals, edit existing ones, or mark inventory as sold
  3. Click "Download [file].js" to get the complete updated file
  4. Replace the old file in your repo with the downloaded one and push
